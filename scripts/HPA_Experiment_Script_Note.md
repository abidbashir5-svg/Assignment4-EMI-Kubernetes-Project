# HPA experiment script note

The HPA workload script (`scripts/run_hpa_experiment.py`) was created directly in the Ubuntu VM from an inline terminal block during the work session and executed there. Its time-series CSV and aggregate summaries are retained under `results/`.

The latest final-repeat time-series CSV was not included in the HPA ZIP supplied for analysis, and no local copy of the VM script was uploaded. This repository package therefore does not fabricate a replacement HPA workload script. The exact HPA manifest, archived telemetry, final aggregate result, code/command description and graphs are included.
